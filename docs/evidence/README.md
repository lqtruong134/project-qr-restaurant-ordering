# Bằng chứng

Xem [hồ sơ đối chiếu](../15-doi-chieu.md) và `../reference/audit.json`. Kết quả rehearsal mới sẽ được script ghi tại đây; không coi kết quả cũ là bằng chứng cho phiên bản mới.

Các tệp `.log` giữ nguyên đầu ra công cụ, kể cả khoảng trắng và kiểu xuống dòng. Chúng được theo dõi bằng Git như bằng chứng; không tự sửa kết quả cũ để khớp một lần kiểm tra mới. Ảnh không gian Notion cá nhân không nằm trong bộ công khai.
